## What we do

- **Websites:** custom-designed, hand-written code instead of site builders and plugin bloat
- **Web applications:** member areas, booking systems, databases, third-party integrations
- **Operations & maintenance:** hosting, updates, backups and monitoring
- **Consulting:** taking over existing sites, hosting migrations, technical assessments

## Principles

- **Made & hosted in Germany:** development and operations in Germany, built with GDPR in mind
- **Fast and low-maintenance:** lean code, few dependencies
- **Privacy by default:** no tracking, no third-party services, self-hosted fonts
- **Accessible:** sufficient contrast, keyboard navigation, alt texts
- **No lock-in:** code, domain and content belong to the client
